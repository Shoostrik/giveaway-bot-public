# Development

Giveaway Bot is developed privately. This repository shows product progress without publishing source code or reusable implementation details.

## English

### Current focus

- consistent and truthful public documentation;
- closed validation of supported giveaway publication;
- result-checking and match-notification quality;
- privacy, support and security readiness;
- preparation for limited testing.

### How progress is shared

Updates describe meaningful user-facing milestones, not raw engineering activity. Each update explains:

1. the user problem;
2. the decision or milestone;
3. why it matters;
4. the next public-safe step.

The project avoids artificial daily reports, commit counts, raw test logs and disclosure of internal architecture.

### Contributions

Before launch, contributions are limited to public documentation, translations and general product feedback. The private source code is not open for external contribution.

## Русский

### Текущий фокус

- единая и правдивая публичная документация;
- закрытая проверка публикации поддерживаемых розыгрышей;
- качество проверки результатов и уведомлений о совпадениях;
- готовность конфиденциальности, поддержки и безопасности;
- подготовка ограниченного тестирования.

### Как рассказываем о прогрессе

Обновления посвящаются важным для пользователя этапам, а не сырой технической работе. Каждая запись объясняет:

1. какую проблему пользователя решали;
2. какое решение или этап завершили;
3. почему это важно;
4. какой безопасный для публикации шаг будет следующим.

Проект не публикует искусственные ежедневные отчёты, количество коммитов, сырые логи тестов и внутреннюю архитектуру.

### Участие

До запуска участие ограничено публичной документацией, переводами и общей обратной связью о продукте. Закрытый исходный код не открыт для внешних изменений.
