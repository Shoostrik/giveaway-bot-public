# Security policy

## English

Giveaway Bot is in pre-launch development. This repository contains public documentation only and no source code, credentials or production configuration.

Do not publish suspected vulnerabilities, personal data, Telegram verification codes, credentials, private links or reproduction details in GitHub Issues or other public channels.

A verified private reporting method will be added before the public service becomes available. Until that method is listed, do not send sensitive vulnerability details through this repository.

A useful future report should include:

- a concise description;
- the affected public service or page;
- safe reproduction steps;
- expected and observed behavior;
- supporting material with sensitive information removed.

GitHub Issues are intended only for general public-documentation and product feedback.

Giveaway Bot will never request a Telegram verification code or payment to receive a prize.

## Русский

Giveaway Bot находится на этапе подготовки к запуску. В этом репозитории есть только публичная документация. Исходного кода, учётных данных и production-конфигурации здесь нет.

Не публикуйте сведения о возможных уязвимостях, персональные данные, коды подтверждения Telegram, учётные данные, закрытые ссылки и шаги воспроизведения в GitHub Issues или других открытых каналах.

Проверенный конфиденциальный способ связи будет добавлен до открытия публичного сервиса. Пока он не указан, не отправляйте чувствительные сведения об уязвимостях через этот репозиторий.

Полезное будущее сообщение должно включать:

- краткое описание;
- затронутый публичный сервис или страницу;
- безопасные шаги воспроизведения;
- ожидаемое и фактическое поведение;
- дополнительные материалы без чувствительной информации.

GitHub Issues предназначены только для общей обратной связи о публичной документации и продукте.

Giveaway Bot никогда не попросит код подтверждения Telegram и не потребует оплату за получение приза.
